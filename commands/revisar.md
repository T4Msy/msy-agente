Revise o diff da branch atual contra a base (`git diff` da branch). Use msy-seguranca para segurança, o checklist do
msy-ux se houver interface e msy-qa para casos de teste. Liste os problemas do mais grave para o menos grave, com
arquivo:linha, o que pode acontecer e como corrigir. Ofereça corrigir junto, explicando cada correção.
